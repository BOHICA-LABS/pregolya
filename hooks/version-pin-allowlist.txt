# version-pin-allowlist.txt — ferrochain factory-artifacts
#
# Per-match exemptions for verify-no-version-pins.sh
#
# Format (one entry per non-comment line):
#   <path-relative-to-.factory/specs> :: <normalized-pin-text>
#
# The separator is ' :: ' (space, double-colon, space).
# <normalized-pin-text> is the exact match string produced by PIN_RE with
# internal whitespace normalized to single spaces — i.e., what
# re.sub(r'\s+', ' ', m.strip()) produces from the regex match object.
#
# Purpose: Exempt specific live-body version pin matches that are grandfathered
# pre-existing historical records written before TD-VSDD-091 was in force.
# These entries exist ONLY for content authored before the rule applied.
# Newly-authored text may NEVER be allowlisted regardless of its content type.
# The retired "justified citations" categories (Red Gate test tables, AC
# source-of-truth tables, historical before-state quotes) were removed as
# permitted bases on 2026-07-24: six consecutive adversarial passes minted
# findings exclusively from that family (CLIP email-notifications Stage-3
# cascade, trend-gate structural intervention).  There are no ongoing permitted
# use categories — grandfathering is the sole remaining basis for any entry.
#
# Each entry MUST have a reason comment on the immediately preceding line.
# Format of reason comment: "# Reason: <justification>"
#
# DESIGN: This scheme is LINE-NUMBER-INDEPENDENT.  Entries survive file edits
# (line additions/deletions above the allowlisted content) because matching is
# keyed on (file, pin-text), not (file, line-number).  A new pin with different
# text still FAILS even if the file has other allowlisted entries.  The same
# historical pin text appearing at multiple locations in the same file is
# covered by a single entry.
#
# Migration note (FIX-BURST-272): migrated from the prior line-number-keyed
# scheme (path:NNN format).  That scheme required manual refresh whenever an
# unrelated edit shifted line numbers; it was patched in bursts 267, 269, and
# 272 for exactly this reason.  Pin-text keying eliminates the drift entirely.
#

# normative benefit.
