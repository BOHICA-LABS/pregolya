# VP-009: Zero-Norm Cosine Guard — Norm-Zero Input Always Returns Err(E-VS-001); Ok(f32::NAN) is Unreachable

## Property Statement

For all possible `Vec<f32>` pairs `(a, b)` with finite elements, `cosine_similarity(a, b)`
never produces `Ok(f32::NAN)`. The guard must fire for BOTH zero-norm AND overflow
conditions before any division. When either norm is `0.0` OR is infinite (sum-of-squares
overflows `f32::MAX` for large elements), the function returns `Err(E-VS-001)`.

**Formal invariant (DI-014):**
```
∀ a: &[f32], b: &[f32], all elements x satisfying x.is_finite():
  let norm_a = a.iter().map(|x| x*x).sum::<f32>().sqrt();
  let norm_b = b.iter().map(|x| x*x).sum::<f32>().sqrt();
  (norm_a == 0.0 ∨ !norm_a.is_finite() ∨ norm_b == 0.0 ∨ !norm_b.is_finite()) →
    cosine_similarity(a, b) == Err(PregolyaError { code: "E-VS-001", .. })
    ∧ cosine_similarity(a, b) ≠ Ok(f32::NAN)
```

No code path through `cosine_similarity` produces `Ok(f32::NAN)` for any input. The guard
fires before any floating-point division; `NaN` propagation through similarity scores is
categorically eliminated.

**Overflow coverage note:** `kani::assume(x.is_finite())` does NOT prevent sum-of-squares
overflow. Individually finite elements (e.g., `1e20f32`) can produce `Σ xᵢ² = +Inf` during
the sum-of-squares step; `sqrt(+Inf) = +Inf`; and `dot / (Inf * Inf) = NaN`. The guard
checks `!norm.is_finite()` (covers overflow) in addition to `norm == 0.0` (covers all-zero).
BC-2.21.003 §Invariant 3 now specifies the combined guard `norm == 0.0 || !norm.is_finite()`;
BC amendment is complete.

## Proof Method

| Method | Tool | Bounded? | Coverage |
|--------|------|----------|----------|
| Model checking | Kani 0.67.0 | Yes — vector length ≤ 8 elements; each `f32` element is symbolic over the full IEEE-754 `f32` range | All symbolic `(a, b)` pairs of length 1..=8; proves that if IEEE-754 sum-of-squares sqrt equals 0.0 for either vector, the function returns `Err(E-VS-001)` and the Ok arm is unreachable |

**Kani async constraint (Kani 0.67.0 has NO native async support):** `cosine_similarity(a: &[f32], b: &[f32]) → Result<f32, PregolyaError>` is a pure-core synchronous function in `vectorstores::similarity` (ADR-014 Decision 2 §Hardening note updated in v1.2: cosine_similarity relocated from vectorstores::mmr to the shared `vectorstores::similarity` module; F-P129-11). No `.await`, no Tokio runtime. The Kani harness calls it directly.

**Harness boundary:** The proof covers `cosine_similarity` as a standalone pure function. The callers (`similarity_search`, `max_marginal_relevance_search`) are effectful and excluded from the Kani scope. The proof establishes that the guard fires in `cosine_similarity`; caller propagation is covered by behavioral tests.

**f32 IEEE-754 handling:** Kani models `f32` symbolically over the full IEEE-754 domain, including `NaN`, `-0.0`, subnormals, and `±Inf`. The harness uses `kani::assume` to restrict to finite (non-NaN) inputs since `NaN` inputs into the norm computation are a separate concern from the zero-norm guard. The proof specifically targets the case where the computed norm equals `0.0` despite possibly non-zero individual elements (e.g., subnormal cancellation).

## Proof Harness Skeleton

Target file: `pregolya-vectorstores/src/similarity.rs`

```rust
// pregolya-vectorstores/src/proofs/cosine_guard.rs  (target fn: vectorstores::similarity::cosine_similarity)

#[cfg(kani)]
mod proofs {
    use super::*;

    /// VP-009: Zero-Norm Guard — norm-zero input always returns Err(E-VS-001)
    /// Proves: Ok(NAN) is unreachable for any symbolic f32 input pair.
    #[kani::proof]
    fn zero_norm_guard_fail_closed() {
        // Bound: vectors of length 1..=8 (tractable for Kani symbolic f32 reasoning)
        let len: usize = kani::any();
        kani::assume(len >= 1);
        kani::assume(len <= 8);

        let a: Vec<f32> = (0..len).map(|_| {
            let x: f32 = kani::any();
            // Restrict to finite values: no NaN/Inf inputs to norm (separate concern)
            kani::assume(x.is_finite());
            x
        }).collect();

        let b: Vec<f32> = (0..len).map(|_| {
            let x: f32 = kani::any();
            kani::assume(x.is_finite());
            x
        }).collect();

        // Compute norms (same formula as production code)
        let norm_a = a.iter().map(|x| x * x).sum::<f32>().sqrt();
        let norm_b = b.iter().map(|x| x * x).sum::<f32>().sqrt();

        let result = cosine_similarity(&a, &b);

        // Overflow and zero-norm guard: covers both IEEE-754 zero AND sum-of-squares overflow.
        // Finite elements can produce norm = +Inf via Σ xᵢ² overflow (e.g., 1e20f32).
        // BC-2.21.003 Invariant 3: "No NaN in any output path" — requires Err on overflow too.
        if norm_a == 0.0 || !norm_a.is_finite() || norm_b == 0.0 || !norm_b.is_finite() {
            // Guard must fire: result must be Err(E-VS-001) for both zero-norm and overflow
            kani::assert(
                matches!(result, Err(PregolyaError { code: "E-VS-001", .. })),
                "zero-norm or overflow guard must return E-VS-001"
            );
            // Ok(NaN) must be unreachable
            kani::assert(
                !matches!(result, Ok(v) if v.is_nan()),
                "Ok(NaN) must be unreachable when norm is zero or overflows to +Inf"
            );
        } else {
            // Both norms are finite and non-zero: cosine must return Ok; result is finite
            kani::assert(result.is_ok(), "finite non-zero norm pair must produce Ok(cosine)");
            if let Ok(cosine) = result {
                kani::assert(cosine.is_finite(), "cosine of finite non-zero vectors must be finite");
            }
        }
    }

    /// Negative: all-zero vector produces norm == 0.0
    #[kani::proof]
    fn all_zero_vector_triggers_guard() {
        let len: usize = kani::any();
        kani::assume(len >= 1);
        kani::assume(len <= 8);

        let zero_vec: Vec<f32> = vec![0.0f32; len];
        let other: Vec<f32> = (0..len).map(|_| {
            let x: f32 = kani::any();
            kani::assume(x.is_finite());
            x
        }).collect();

        let result = cosine_similarity(&zero_vec, &other);

        kani::assert(
            matches!(result, Err(PregolyaError { code: "E-VS-001", .. })),
            "all-zero query vector must return E-VS-001"
        );
    }

    /// Overflow guard: large-magnitude elements produce norm = +Inf; guard must fire before division.
    /// BC-2.21.003 Invariant 3: "No NaN in any output path" — overflow produces Inf/Inf = NaN
    /// if unchecked. The guard must check !norm.is_finite() in addition to norm == 0.0.
    /// This harness uses f32::MAX elements: MAX^2 overflows to +Inf; sqrt(+Inf) = +Inf.
    #[kani::proof]
    fn overflow_norm_triggers_guard() {
        let len: usize = kani::any();
        kani::assume(len >= 1);
        kani::assume(len <= 8);

        // f32::MAX squared overflows to +Inf; norm = sqrt(+Inf) = +Inf (not 0.0)
        // The zero-norm guard alone (norm == 0.0) does not fire — overflow guard required.
        let overflow_vec: Vec<f32> = vec![f32::MAX; len];
        let other: Vec<f32> = (0..len).map(|_| {
            let x: f32 = kani::any();
            kani::assume(x.is_finite());
            x
        }).collect();

        let result = cosine_similarity(&overflow_vec, &other);

        // Overflow path: norm = +Inf; guard must fire; Err(E-VS-001) required
        kani::assert(
            matches!(result, Err(PregolyaError { code: "E-VS-001", .. })),
            "overflow-norm vector (norm = +Inf) must return E-VS-001"
        );
        // Ok(NaN) from Inf/Inf division must be unreachable
        kani::assert(
            !matches!(result, Ok(v) if v.is_nan()),
            "Ok(NaN) from Inf/Inf division must be unreachable via overflow guard"
        );
    }
}
```

## Feasibility Assessment

**Feasibility: MEDIUM-HIGH**

| Factor | Assessment | Notes |
|--------|-----------|-------|
| Input space size | Bounded | Vector length ≤ 8; `f32` elements are symbolic but finite; Kani models IEEE-754 f32 symbolically |
| Proof complexity | Medium | The guard is 2 lines; the proof traces a single conditional before division; NaN propagation model adds complexity but is well-supported by Kani's f32 modeling |
| Tool support | Supported | Kani 0.67.0; `cosine_similarity` is pure-core sync; `f32` symbolic reasoning is supported; `is_finite()`, `is_nan()`, `sqrt()` are modeled |
| Estimated proof time | 5–15 min | Symbolic f32 arithmetic over bounded vectors; CBMC f32 model adds overhead vs integer proofs |

Key factors:
1. `cosine_similarity` is a pure-core synchronous function with no I/O and no async (ADR-014
   Decision 2 §Hardening note). Kani 0.67.0 compatible without any adaptation.
2. The guard is the first operation — Kani's symbolic execution directly verifies the guard
   fires before any division operation is reachable.
3. The critical proof is reachability: prove that the `Ok` arm containing the division result
   is unreachable when `norm_a == 0.0 || norm_b == 0.0`. CBMC's SAT solver handles this
   as a simple conditional reachability query.

**Known constraint:** Kani's f32 symbolic model may require loop-unwinding bounds for the
`sum::<f32>()` iterator over the length-bounded vector. The implementer must add
`#[kani::unwind(9)]` (len ≤ 8 elements + 1) to the proof harness to prevent CBMC
loop-unwinding assertion failures.

**Blocking risk (LOW):** If CBMC's f32 model produces overly conservative results for
`sqrt(0.0) == 0.0` (IEEE-754 exact), the implementer may need to add an explicit `kani::assume`
asserting that `sqrt(sum_of_zero_squares) == 0.0`. This is a known tractable pattern in
Kani f32 proofs.
