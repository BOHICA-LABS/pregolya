# VP-003: Workspace Path Confinement

## Property Statement

For any input path, `canonicalize_beneath_root(base, path)` either:
(a) returns `Ok(p)` where `p.starts_with(base)` is true, or
(b) returns `Err(FerrochainError { code: "E-SBXD-001", .. })` (canonical form; crate-internal
    `SandboxError::WorkspaceEscape` converts via `Into<FerrochainError>`).

It never returns `Ok(p)` where `p` does not start with `base`.

**Formal invariant (DI-007):** `∀ base path: Path, canonicalize_beneath_root(base, path) ≠ Ok(p) where !p.starts_with(base)`

## Source Contract

- **BC:** BC-2.13.004 — All Workspace File Ops Call canonicalize_beneath_root at Access Time (NE-02) — Kani VP Seed
- **Postcondition/Invariant:** Postcondition 4 — if the canonical resolved path does NOT have the workspace root as a prefix, `Err(E-SBXD-001: WorkspaceEscape)` is returned and no file operation occurs; the function never returns `Ok(p)` where `!p.starts_with(base)`. Invariant 1 — `canonicalize_beneath_root` is called at access time, not at path construction time or as a pre-validation step that is later bypassed.

## Proof Harness Skeleton

Target file: `ferrochain-sandbox/src/path_guard.rs`

```rust
#[cfg(kani)]
mod proofs {
    use super::*;

    /// VP-003: Workspace Path Confinement
    /// Proves: canonicalize_beneath_root never returns a path outside the base.
    #[kani::proof]
    fn workspace_confinement_harness() {
        // Symbolic base directory (bounded path component count)
        let base_components: Vec<BoundedPathComponent> = kani::vec(3, kani::any);
        let base = PathBuf::from_components(&base_components);

        // Symbolic target path (may attempt traversal)
        let path_components: Vec<BoundedPathComponent> = kani::vec(6, kani::any);
        let path = PathBuf::from_components(&path_components);

        // Note: canonicalize_beneath_root_pure returns Result<PathBuf, FerrochainError>
        // at the contract boundary. SandboxError::WorkspaceEscape is crate-internal and
        // converts via Into<FerrochainError> to E-SBXD-001 (taxonomy: component=SBXD,
        // category=SECURITY). The harness asserts the canonical BC contract form.
        match canonicalize_beneath_root_pure(&base, &path) {
            Ok(p) => {
                kani::assert(
                    p.starts_with(&base),
                    "canonicalize_beneath_root returned a path outside the base"
                );
            }
            Err(FerrochainError { code: "E-SBXD-001", .. }) => {
                // Canonical: workspace escape detected — FerrochainError{component: SBXD,
                // category: SECURITY, code: "E-SBXD-001"} per error-taxonomy.md §SBXD
            }
            Err(other) => {
                // Other errors are allowed (e.g., path does not exist in model)
                let _ = other;
            }
        }
    }

    /// Specific symlink traversal: "../../../etc/passwd" pattern
    #[kani::proof]
    fn dotdot_traversal_rejected() {
        let base = PathBuf::from("/workspace");
        let traversal = PathBuf::from("/workspace/subdir/../../etc/passwd");

        let result = canonicalize_beneath_root_pure(&base, &traversal);

        // Assert canonical FerrochainError form at BC contract boundary (E-SBXD-001).
        kani::assert(
            matches!(result, Err(FerrochainError { code: "E-SBXD-001", .. })),
            "dotdot traversal must return FerrochainError{code: E-SBXD-001} (WorkspaceEscape)"
        );
    }
}
```

## Feasibility Assessment

**Feasibility: MEDIUM-HIGH**

Key factors:
1. The proof operates on a **pure model** of path canonicalization (`canonicalize_beneath_root_pure`),
   not on `std::fs::canonicalize` which calls the OS.
2. The pure model resolves `..` components symbolically without touching the filesystem.
3. Path component representation must be bounded for Kani: each component is ≤ 255 bytes.
4. Symlink resolution in the pure model is approximated: symlinks are assumed to point to
   bounded-length paths (no infinite symlink chains).

| Factor | Assessment | Notes |
|--------|-----------|-------|
| Input space size | Bounded | ≤ 3 base components, ≤ 6 path components, each ≤ 255 bytes |
| Proof complexity | Medium | Pure model resolves `..` symbolically; no OS calls; bounded symlink model |
| Tool support | Supported | Kani 0.67.0; pure function model; `kani::Arbitrary` derivable for `BoundedPathComponent` |
| Estimated proof time | < 10 min | Bounded path component space; within CI budget |

**Key design decision required:** `canonicalize_beneath_root` must be split into:
- `canonicalize_beneath_root_pure(base, path) → Result<PathBuf, FerrochainError>` — pure, Kani-provable; returns canonical `FerrochainError { component: SBXD, category: SECURITY, code: "E-SBXD-001" }` on escape (crate-internal `SandboxError::WorkspaceEscape` converts via `Into<FerrochainError>`)
- `canonicalize_beneath_root(base, path) → Result<PathBuf, FerrochainError>` — calls OS `std::fs::canonicalize` then delegates to pure layer

The Kani harness proves the pure layer. Integration tests verify the full OS-calling layer.

**Blocking risk:** If the pure model does not accurately represent OS symlink resolution,
the proof may pass while the OS-level function has escape paths. Mitigation: integration tests
with adversarial symlink fixtures (symlinks created programmatically) must be part of the test suite.
