# VP-015: MCP Response Credential Redaction — API Key Patterns Replaced with <redacted> Before Transmission (CWE-532)

## Property Statement

For any `tools/call` invocation where `DynTool::invoke_dyn` returns `Err(PregolyaError { message, .. })`,
the MCP server's `CallToolResult` response `content[0].text` MUST NOT contain API key material
matching the OpenAI, Anthropic, or generic long-token patterns defined in
`pregolya_mcp::sanitize::redact_credentials`. Before the message text is placed in the response,
`redact_credentials(message)` transforms it — any matching pattern is replaced with `<redacted>`.

**Formal property (DI-010, CWE-532/522):**

```
∀ err: PregolyaError,
∀ pattern ∈ {
    OpenAI key:      sk-[A-Za-z0-9_\-]{20,},
    Anthropic key:   sk-ant-[A-Za-z0-9_\-]{32,},
    Generic token:   [A-Za-z0-9]{64,},
    Bearer token:    Bearer\s+[A-Za-z0-9._~+/=\-]+,
    URL userinfo:    [a-zA-Z][a-zA-Z0-9+.\-]*://[^/\s:@]+:[^/\s:@]+@,
    HTTP Basic auth: Basic\s+[A-Za-z0-9+/=]+
  }:
  err.message matches pattern
    → mcp_response.content[0].text does NOT match pattern
      AND mcp_response.content[0].text contains "<redacted>"
```

The sanitization step is mandatory and unconditional on every `isError: true` MCP
`CallToolResult`. No bypass path exists — no feature flag, no debug mode, no opt-out.

Source restriction: only `PregolyaError::message` is used as the text source passed to
`redact_credentials`. The `.source()` chain, `Debug` output, and `Display` output are never
included in the MCP response content.

**SEC-BOUND-001 pipeline context:** BC-2.09.007 {PC-003} applies a 2-step sanitization
pipeline (step 1 N/A; step 2 `redact_credentials`; step 3 `sanitize_internal_ids`). VP-015
covers step 2 only — the 6-pattern `redact_credentials` function. Step 3 (`sanitize_internal_ids`
UUID-shape replacement → `<redacted-id>`) is non-VP-elevated and covered by BC-2.09.007 TV-011
directed test, consistent with the R38/F-P2A161-01-Option-B adjudication.

## Source Contract

- **BC:** BC-2.09.007 — MCP Server Tool Invocation (tools/call; External Client Executes Registered Tool)
- **Invariant {INV-003} (SEC-BOUND-001 step 2):** Mandatory credential redaction — `PregolyaError::message`
  is passed through `pregolya_mcp::sanitize::redact_credentials` before inclusion in `content[0].text`.
  The `.source()` chain, `Debug`, and `Display` are never used as the text source. Rules in order:
  (1) OpenAI `sk-[A-Za-z0-9_\-]{20,}` → `<redacted>`
  (2) Anthropic `sk-ant-[A-Za-z0-9_\-]{32,}` → `<redacted>`
  (3) Generic `[A-Za-z0-9]{64,}` → `<redacted>`
  (4) Bearer token `Bearer\s+[A-Za-z0-9._~+/=\-]+` → `<redacted>` (entire `Bearer <token>` span; covers RFC 6750 tokens including JWTs and short opaque tokens not matching patterns 1–3)
  (5) URL-embedded userinfo `[a-zA-Z][a-zA-Z0-9+.\-]*://[^/\s:@]+:[^/\s:@]+@` → `<redacted>` (covers `scheme://user:password@host`; auth-bearing `OllamaBaseUrl` is the live production vector)
  (6) HTTP Basic auth `Basic\s+[A-Za-z0-9+/=]+` → `<redacted>` (base64-encoded `user:pass`; `+`/`=` padding chars prevent pattern 3's 64+ pure-alphanumeric rule from matching)
- **Postcondition {PC-003}:** Mandatory 2-step sanitization applied in the tool-error path (step 1
  N/A; step 2 `redact_credentials` 6-pattern set — covered by VP-015; step 3 `sanitize_internal_ids`
  UUID-shape replacement — non-VP-elevated, covered by TV-011 directed test); sanitized string placed
  in `content[0].text`.
- **Test vectors:** TV-007 (OpenAI `sk-abc123XYZabc123XYZabc` pattern → `<redacted>`); TV-010 (Bearer
  token → `<redacted>`); TV-012 (URL-embedded userinfo → `<redacted>`); TV-013 (HTTP Basic auth
  `Basic dXNlcjpwYXNzd29yZA==` → `<redacted>`).

## Proof Harness Skeleton

Target file: `pregolya-mcp/src/sanitize.rs`

Harness function: `credential_redaction_unit`

```rust
// pregolya-mcp/src/sanitize.rs
// VP-015 — credential_redaction_unit harness

#[cfg(test)]
mod tests {
    use super::*;

    /// VP-015 — OpenAI key pattern is redacted.
    #[test]
    fn credential_redaction_unit_openai() {
        let input = "request failed: key=sk-abc123XYZabc123XYZabc";
        let result = redact_credentials(input);
        assert!(
            !result.contains("sk-abc"),
            "OpenAI key must not appear in output; got: {result}"
        );
        assert!(
            result.contains("<redacted>"),
            "output must contain <redacted>; got: {result}"
        );
    }

    /// VP-015 — Anthropic key pattern is redacted.
    #[test]
    fn credential_redaction_unit_anthropic() {
        // 32+ alphanumeric chars after sk-ant-
        let key = "sk-ant-api03-".to_owned() + &"X".repeat(40);
        let input = format!("auth failed: {key}");
        let result = redact_credentials(&input);
        assert!(
            !result.contains("sk-ant-"),
            "Anthropic key must not appear in output; got: {result}"
        );
        assert!(
            result.contains("<redacted>"),
            "output must contain <redacted>; got: {result}"
        );
    }

    /// VP-015 — Generic long alphanumeric token (64+ chars) is redacted.
    #[test]
    fn credential_redaction_unit_generic_long_token() {
        let token = "A".repeat(64);
        let input = format!("token={token}");
        let result = redact_credentials(&input);
        assert!(
            !result.contains(&token),
            "generic long token must not appear in output; got: {result}"
        );
        assert!(
            result.contains("<redacted>"),
            "output must contain <redacted>; got: {result}"
        );
    }

    /// VP-015 — Plain text without key patterns passes through unchanged.
    #[test]
    fn credential_redaction_unit_clean_passthrough() {
        let input = "request failed: HTTP 429 Too Many Requests";
        let result = redact_credentials(input);
        assert_eq!(
            result.as_ref(),
            input,
            "clean text must pass through unchanged"
        );
    }

    /// VP-015 — Bearer token pattern (pattern 4) is redacted.
    #[test]
    fn credential_redaction_unit_bearer_token() {
        let input = "auth failed: Bearer eyJhbGciOiJIUzI1NiJ9.shorttoken";
        let result = redact_credentials(input);
        assert!(
            !result.contains("Bearer"),
            "Bearer token span must not appear in output; got: {result}"
        );
        assert!(
            result.contains("<redacted>"),
            "output must contain <redacted>; got: {result}"
        );
    }

    /// VP-015 — URL-embedded userinfo pattern (pattern 5) is redacted.
    #[test]
    fn credential_redaction_unit_url_userinfo() {
        let input = "connection failed: http://admin:secret@db.internal:5432/data";
        let result = redact_credentials(&input);
        assert!(
            !result.contains("admin:secret"),
            "URL userinfo must not appear in output; got: {result}"
        );
        assert!(
            result.contains("<redacted>"),
            "output must contain <redacted>; got: {result}"
        );
    }

    /// VP-015 — HTTP Basic auth pattern (pattern 6) is redacted.
    #[test]
    fn credential_redaction_unit_basic_auth() {
        // base64 of "user:password" — contains "=" padding chars that prevent
        // pattern 3 (64+ pure-alphanumeric) from matching; pattern 6 catches it.
        let input = "auth rejected: Basic dXNlcjpwYXNzd29yZA==";
        let result = redact_credentials(&input);
        assert!(
            !result.contains("dXNlcjpwYXNzd29yZA=="),
            "Basic auth credential must not appear in output; got: {result}"
        );
        assert!(
            result.contains("<redacted>"),
            "output must contain <redacted>; got: {result}"
        );
    }
}
```

**Source-restriction discipline note:** The seven harnesses above test `redact_credentials` in
isolation. The obligation that only `PregolyaError::message` is passed to this function (never
`.source()`, `Debug`, or `Display`) is enforced by code review at the `mcp::server` call site —
specifically, the single call site in the `tools/call` error-response path in `server.rs`.
