# VP-004: MCP ToolException Type-Identity Preservation

## Property Statement

When an MCP server raises a bare `ToolException`, the ferrochain MCP adapter re-raises it
as an `MCP ToolException` error preserving exact type identity. The error type is not
downcast, wrapped in a generic error, or silently converted to a string error.

**Invariant (DI-014):** MCP tool errors propagate as `Err(FerrochainError { code: "E-MCP-001", ... })`
with the original exception type information preserved in the error source chain.

## Source Contract

- **BC:** BC-2.09.004 — MCP Bare ToolException Re-Raise Preserving Type Identity (Red Gate — R11)
- **Postcondition/Invariant:** Postcondition 1 — the caller observes `Err(FerrochainError { component: MCP, category: TOOL, code: E-MCP-001, message: "ToolException: MCP server '<server>' raised ToolException for tool '<tool>': <message>" })`; Postcondition 4 — `FerrochainError::source` retains the original `McpError::ToolExecution` for downstream introspection; the `handle_tool_errors` flag does NOT suppress this path.

## Proof Harness Skeleton

**Tool:** Integration test (behavioral — not Kani-tractable; involves I/O transport)

Red Gate test: `tests/red_gate/test_BC_2_09_004_mcp_tool_exception.rs`

Test scenario: mock MCP server that raises a bare `ToolException`; assert that the
ferrochain adapter surfaces `Err(FerrochainError { code: "E-MCP-001", ... })` with
the original exception type accessible via `error.source()`.

```rust
// tests/red_gate/test_BC_2_09_004_mcp_tool_exception.rs
// Red Gate: must compile and FAIL before implementation (error swallowed or wrong code)

#[tokio::test]
async fn bc_2_09_004_bare_tool_exception_preserves_type_identity() {
    let mock_server = MockMcpServer::new_raises_tool_exception("unauthorized: tool requires auth");
    let client = McpTool::connect(mock_server.config()).await.unwrap();

    let result = client.run(ToolInput::default()).await;

    assert!(result.is_err());
    let err = result.unwrap_err();
    assert_eq!(err.code(), "E-MCP-001");
    assert_eq!(err.category(), Category::Tool);
    assert!(err.source().is_some(), "original exception must be in source chain");
}

#[tokio::test]
async fn bc_2_09_004_handle_tool_errors_flag_irrelevant() {
    // handle_tool_errors=false: bare ToolException path must still propagate as E-MCP-001
    let mock_server = MockMcpServer::new_raises_tool_exception("auth failure");
    let client = McpTool::connect_with_options(
        mock_server.config(),
        McpOptions { handle_tool_errors: false, ..Default::default() },
    ).await.unwrap();

    let result = client.run(ToolInput::default()).await;
    let err = result.unwrap_err();
    assert_eq!(err.code(), "E-MCP-001");
}
```
